# jimbostack
A personal web site based on HUGO https://gohugo.io/ <br>
It uses neither modules nor themes <br>
It is a plain vanilla site, based on 
```
hugo new site <site name>>
```
Pages are added via 
```
hugo new content content/posts/my-first-post.md
```
The site is run using 
```
hugo server --noHTTPCache --disableFastRender
```
and then open localhost:1313 <br>

## The vibe of it all
I use neither modules nor themes as they introduce many new technologies I just don't need <br>
Any formatting is handled via one single css in /static/css/style.css and I let AI recommend the formatting <br>
This project was inspired by https://www.youtube.com/watch?v=ZFL09qhKi5I <br>
Following the the motto **"Simple is beautiful"** and **"Less is more"** <br>
It posits **"The most effective, maintainable, and elegant software solutions are those that avoid unnecessary complexity"**
